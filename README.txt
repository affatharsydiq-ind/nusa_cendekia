SMA NUSA CENDEKIA — WEBSITE DEMONSTRASI

Halaman:
- index.html: Home
- pendaftaran.html: Info PPDB
- form.html: Formulir pendaftaran
- assets/style.css: CSS responsif
- assets/main.js: menu mobile, validasi form, dan modal simulasi

Cara menjalankan:
1. Extract ZIP dan buka folder di VS Code.
2. Jalankan index.html menggunakan Live Server atau browser.
3. Internet dibutuhkan untuk Tailwind CDN, Google Fonts, dan foto Unsplash.

Catatan: website statis, tanpa database/backend. Formulir tidak mengirim atau menyimpan data. Nomor registrasi hanya simulasi. Kontak, alamat, berita, jadwal, dan persyaratan adalah data dummy. Tahun PPDB 2025/2026 mengikuti prompt dan dapat diedit.
